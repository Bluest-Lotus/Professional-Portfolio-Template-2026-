# Stacklet Robot

Stacklet is a fully open‑source, Cozmo‑style robot designed around modular hardware and a custom embedded OS.  
It’s built to be teachable, hackable, and expandable.

---

## 🔧 Hardware Overview

- ESP32‑S3 microcontroller  
- Dual stepper motors  
- Time‑of‑flight distance sensor  
- IMU for orientation  
- Magnetic encoder wheels  
- USB‑C charging + programming  

---

## 🧠 Software Architecture

Stacklet runs a tiny embedded OS I designed:

- Modular app framework  
- Event‑driven input system  
- Real‑time motor control  
- Hot‑swappable behaviors  
- Serial + BLE debugging  

---

## 🎨 Design Goals

- Feel like a “mini companion robot”  
- Be fully open‑source  
- Be easy for students to modify  
- Support future modules (arm, camera, gripper)
